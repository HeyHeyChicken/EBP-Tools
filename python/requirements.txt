# Versions épinglées. Sans elles, chaque passage du CI réinstalle les dernières
# versions publiées : deux constructions de la même source donnent alors des
# analyzers différents, et surtout une publication amont peut casser l'analyzer
# sans le moindre changement de code — ce qui ne se verrait qu'en production.
# Le cas s'est déjà produit : le binaire construit embarque onnxruntime 1.19.2
# alors qu'une reconstruction en installerait 1.27.0, huit versions plus loin.
#
# Relevé depuis le venv de build (python/.venv). Pour les faire évoluer :
# supprimer .venv, réinstaller sans contrainte, reconstruire, vérifier que
# `selftest` passe (il garantit l'OCR in-process), puis reporter `pip freeze`.
#
# Seules les dépendances directes sont épinglées ; les transitives suivent leur
# résolution, qui diffère de toute façon d'une plateforme à l'autre (pefile sous
# Windows, macholib sous macOS).

numpy==2.5.1
Pillow==12.3.0
pytesseract==0.3.13
# In-process OCR accelerator (~3.65x on the analysis phase). Native build that
# links libtesseract/leptonica + pulls cysignals — only installable from source
# where the dev libs exist, hence the macOS-only marker here.
#   - macOS: built from source here (build validated end-to-end).
#   - Windows: NOT from source (won't compile); build.bat installs a prebuilt
#     wheel (simonflueckiger) that bundles the tesseract DLLs.
#   - Linux: add later (needs libtesseract-dev/libleptonica-dev in CI).
# Anywhere tesserocr ends up absent, eva_ocr.py falls back to pytesseract.
tesserocr==2.10.0; sys_platform == "darwin"
opencv-python==5.0.0.93
pyinstaller==6.21.0
scipy==1.18.0
# macOS Intel : Microsoft a cessé de publier des roues x86_64 après la 1.23.2.
# La contrainte n'est donc pas un choix, c'est ce que l'index propose encore.
# Le modèle est un export PyTorch 2.8 que cette version charge sans difficulté,
# mais rien ne le vérifie automatiquement : `selftest` ne contrôle que le
# backend OCR. Les Mac Intel tournent donc sur un runtime d'inférence plus
# ancien que les autres plateformes.
# `not` n'existe pas dans la grammaire PEP 508 : la condition est donc
# écrite par De Morgan, « pas macOS, ou pas Intel ».
onnxruntime==1.27.0; sys_platform != "darwin" or platform_machine != "x86_64"
onnxruntime==1.23.2; sys_platform == "darwin" and platform_machine == "x86_64"
